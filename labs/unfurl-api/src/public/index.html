Node2Shell Lab

Link Unfurl API

A small OG scraper. Give it a URL and it fetches the page, reads the complete body, and returns a preview.

This lab accepts loopback and host-gateway targets only.

Result


      


      

        

          
API

          
POST /api/unfurl
Content-Type: application/json

{"url":"http://host.docker.internal:4000/"}

        

        

          
Runtime

          
Node.js v24.22.0 with undici 8.12.3. The response body is always consumed so the preview can inspect metadata.
